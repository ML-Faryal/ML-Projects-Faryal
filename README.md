## Project 1: Spam Email Classifier
This project uses Naive Bayes algorithm to classify emails as Spam or Not Spam.

**Key Features:**
- Data Cleaning and Text Preprocessing
- TF-IDF Vectorization 
- Naive Bayes Model Training
- Model Evaluation using Accuracy, Precision, Recall, F1-Score
- Confusion Matrix Visualization

**Technologies Used:** 
Python, Pandas, NumPy, Scikit-learn, Matplotlib

**How to Run:**
1. Download the `Spam_Classifier.ipynb` file
2. Make sure `spam.csv` dataset is in the same folder
3. Run all cells in Jupyter Notebook
